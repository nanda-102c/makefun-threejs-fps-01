STRIKE LANE — a round-based tactical FPS in three.js. Two teams fight short rounds on the Foundry Yard: plant the spike at site A or B, or wipe the Wardens. Money earned each round buys rifles, SMGs, a shotgun and grenades; bots walk the lanes, hold sites, see and hear, and shoot back. First to 5 rounds takes the match.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
